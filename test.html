To use this template:

  1. Replace 'default-cursor.png', 'pointer-cursor.png', and 'link-cursor.png' with the actual paths to your cursor image files.
  2. Ensure your image files are in the correct location relative to your HTML file or provide the full URL.
  3. The browser will try to use your custom image first, and if it fails, it will fall back to the cursor type specified after the comma (e.g., 'auto', 'pointer').
  4. Apply the 'clickable' class to elements you want to have the custom pointer cursor.
  5. You can also apply custom cursors inline using the 'style' attribute as shown in the second paragraph.
  6. For standard cursors (like 'text', 'grab', 'grabbing'), you can directly apply them via CSS to the relevant elements.

Remember that the best format for custom cursors are often '.cur' (for static cursors) and '.ani' (for animated cursors), as they are specifically designed for this purpose and have broader browser support. However, some browsers also support '.png', '.gif', and other image formats for custom cursors.
